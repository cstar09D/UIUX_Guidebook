# 콘텐츠 관리자 사용 안내

현재 작업 공간은 이 컴퓨터에서 실행하는 단일 관리자 환경입니다. `/admin`에서 다크 관리자를 열고 `/`에서 게시된 사이트를 확인합니다.

## 용어 작성과 게시

1. ‘용어 추가’에서 이름·발음·한국어 표현·요약·카테고리·별칭·움직임 검색어·태그·지원 환경·출처와 시뮬레이션을 지정합니다.
2. ‘사용 가이드’에서 정의·사용 상황·흐름·주의점·대안·체험 방법을 편집합니다. 제목/설명 항목은 추가·삭제·위아래 이동이 가능합니다.
3. ‘화면 예시’에서 상태 선택 이름, 발생 조건, 처리 방법, 실제 화면의 제목·문구·목록·행동·상태를 편집합니다. 예시는 연결한 UI의 설명용 화면으로 그려집니다.
4. ‘직무별 안내’에서 각 직무의 목표·작업·전달 예시·검토 질문을 작성합니다.
5. 미완성 내용은 ‘초안 저장’합니다. ‘저장된 초안 보기’는 마지막 저장 내용만 보여주며, 저장하지 않은 편집은 반영하지 않습니다.
6. ‘게시’하면 필수 상세 내용과 출처·환경을 검증한 뒤 게시본을 갱신합니다. 초안 저장만으로 기존 게시본이 바뀌지 않습니다.

새 콘텐츠는 초안이므로 게시 전까지 목록·검색·직접 링크로 공개되지 않습니다. 이미 게시된 콘텐츠를 수정하면 ‘미게시 변경’으로 표시합니다. ‘게시 취소’는 게시본을 제거하고 초안과 이력을 남깁니다.

기본 가이드 불러오기는 선택한 시뮬레이션의 시작용 내용을 편집기에 복사합니다. 실제 용어와 맞는지 검토해야 하며, 시뮬레이션 연결만 바꿨을 때는 기존 설명을 자동으로 덮어쓰지 않습니다.

## 숨김·순서·휴지통

숨김과 휴지통 이동은 즉시 사이트의 목록·검색·직접 링크에서 제외합니다. 게시본과 이력은 보존합니다. 휴지통에서 복원하면 기존 게시 여부와 숨김 상태에 따라 다시 표시됩니다.

순서는 위·아래 버튼으로 조정합니다. 카테고리를 선택하면 그 분류 안의 이웃 항목과 순서를 바꿉니다. 이름 검색 중에는 순서 변경을 비활성화해 의도하지 않은 이동을 막습니다.

## 카테고리와 태그

카테고리·태그의 추가, 이름 변경, 순서 변경, 삭제를 지원합니다. 카테고리 순서는 사이트 필터 순서에 반영됩니다. 이름 변경은 초안과 게시본에 함께 반영합니다.

사용 중인 카테고리를 삭제할 때는 이동할 카테고리를 선택합니다. 마지막 카테고리는 삭제할 수 없습니다. 태그 삭제는 현재 초안·게시본의 연결을 제거합니다. 과거 이력의 분류 기록은 보존합니다.

별칭은 다른 명칭을 설명하는 용어별 정보입니다. 태그는 여러 콘텐츠를 묶는 공용 분류이며, 움직임 검색어는 검색을 위한 표현입니다. 모두 검색에 사용됩니다.

## 변경 이력과 복원

편집기의 ‘변경 이력’에서 각 버전의 내용과 전체 기록을 확인합니다. 선택한 버전은 새 초안으로 복원하며 현재 게시본은 유지됩니다. 복원한 초안을 확인한 뒤 게시하세요.

복원은 현재 순서·숨김·휴지통 상태를 유지합니다. 과거 카테고리가 삭제된 경우 현재 카테고리를 유지하며, 삭제된 태그는 되살리지 않습니다. 다른 창에서 먼저 수정한 경우 오래된 버전으로 저장하거나 복원하지 못하도록 충돌을 알립니다.

## 백업과 가져오기

전체 백업은 초안·게시본·휴지통·분류·이력을 포함한 version 2 JSON입니다. 시뮬레이션과 앱 실행 소스는 포함하지 않으므로 프로젝트 폴더도 별도로 보관합니다. 파일은 25MB 이하로 가져올 수 있습니다.

- 병합: 같은 id를 파일 내용으로 갱신하고 새로운 id를 추가합니다. 파일에 없는 기존 콘텐츠와 분류는 유지합니다.
- 전체 교체: 파일 기준으로 콘텐츠·게시본·분류·이력을 교체합니다. 파일에 없는 콘텐츠는 제거합니다.

파일을 선택한 뒤 ‘변경 내용 검토’로 추가·덮어쓰기·제거 대상과 게시 상태를 확인합니다. 확인 체크 후 적용하며, 검토 후 데이터가 바뀌면 다시 검토해야 합니다. 알 수 없는 시뮬레이션이나 잘못된 스키마는 저장 전에 거부합니다.

적용 직전의 전체 백업을 `data/backups/`에 자동 생성합니다. ‘자동 복구 지점’에서 내려받아 다시 검토·가져오기 하면 복원할 수 있습니다. 이전 프로토타입의 version 1 메타데이터 JSON도 기본 가이드를 연결해 변환합니다.

## 데이터 구조

`terms`에는 현재 편집본, `published_terms`에는 마지막 게시본, `term_versions`에는 변경 기록을 저장합니다. `settings`는 스키마 버전과 카테고리·태그를, `content_meta`는 수정 시간을 관리합니다. 숨김·휴지통·목록 순서는 현재 편집본의 운영 상태를 적용합니다.

기존 SQLite 파일은 첫 실행 시 한 번 이전합니다. 이전 전 메타데이터를 백업하고 기존 명칭·요약·검색어·숨김·휴지통·순서를 보존합니다. 이후 재시작이나 빌드는 관리자 콘텐츠를 초기화하지 않습니다.
