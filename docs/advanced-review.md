# 4단계 탐색·상태·조작·레이아웃 검수

확인일: 2026-11-27. [4단계 명세](planning/advanced-spec.md)에 따라 남은 기본 유형 12개를 추가했습니다. 기본 유형 50개와 별도 Date Picker (Range) 1개로 총 51개입니다. 새 유형은 목록의 자동 반복, 실제 체험, React·TypeScript와 독립 HTML·CSS·JavaScript, 상세 가이드·직무별 안내·연결 대안을 제공합니다.

## 자동 검사

프로덕션 빌드와 테스트 49개가 통과했습니다. 등록된 UI 51개·상태별 화면 예시 158개·4개 직무별 안내·대안 연결의 유효성, 독립 React 부분·전체 코드 102개의 타입과 HTML·CSS·JavaScript 구문, 검색·재생·저장·게시·충돌·백업·일회성 추가 이전을 포함합니다. 별도 임시 DB에서 기존 초안·게시본·휴지통·순서·이력 보존을 검사합니다.

새 순수 로직 검사는 정렬의 원본 불변·동일 값 순서, 필터 AND·해제·0건, 순서 이동의 경계·id 보존, 접힌 트리의 탐색 제외, 이징의 끝점·단조 증가·중간 속도를 다룹니다.

## 실제 조작

Aside 브라우저와 임시 DB의 프로덕션 서버에서 아래 동작을 React·HTML 양쪽에서 확인했습니다.

| UI | 검증한 동작 |
|---|---|
| Tree View | 오른쪽 펼침·자식 이동, Enter로 문서 선택, Home에서 선택 유지, 왼쪽 접기 후 자식 탐색 제외 |
| Carousel | 이전으로 마지막 이동·다음으로 처음 순환, 위치 버튼의 특정 장 이동, 제목·위치 안내 일치 |
| Data Table | 12월의 한 항목과 합계, 조회 실패에서 기존 12월 표·caption 유지, 10월 0건 안내 |
| Snackbar | 실제 보관·실행 취소, 초점이 알림에 있을 때 6초 이상 유지, 닫기·Esc에서 보관 유지, 별도 복원 |
| Empty State | 첫 노트 생성, 필터 무결과·초기화, 조회 실패·재실패·재시도 성공, 결과 목록 초점 |
| Sorting | 낮은 금액순·높은 금액순·기본순 복귀, 같은 금액의 안정적 순서 |
| Filtering | 기획 2건 + 내 담당 0건의 AND, 분류만 해제해 내 담당 2건 유지, 개별 해제·전체 초기화 |
| Load More | 2→4→6개, 첫 추가 항목 초점, 끝에서 버튼 제거, 실패 시 기존 항목 보존, 취소 후 지연 추가 없음 |
| Drag and Drop | 실제 포인터 드래그로 첫 항목을 마지막으로 이동, Esc 취소·목록 밖 놓기, 위·아래 버튼·끝 제한·초기화 |
| Responsive Layout | 실제 컨테이너 너비에 따른 3열·1열 전환, 동일 내용·순서 유지 |
| Sticky Header | 내부 180px 스크롤에서 헤더 상단 유지, 고정 해제 시 본문과 이동, 맨 위 복귀. 위치를 실제 bounding box로 비교 |
| Easing | ease-in의 중간 위치가 linear보다 느림, 곡선 변경 시 이전 실행 취소, 두 점 모두 종점 100% 도착·초기화 |

포인터 검증 중 HTML 초기 순서 버튼의 연결 속성 누락을 발견해 수정하고 두 형식을 재확인했습니다. 드래그 시작에서 내부 영역으로 초점을 옮겨 Esc 취소가 동작하도록 보완했습니다. 더 보기의 실패·취소 후 버튼 초점과 실행 중 취소 버튼 초점도 처리했습니다.

서버 요청·문서 선택·보관·조회는 외부 서비스를 변경하지 않는 예제 상태입니다. 실제 API 연결 시 권한·요청 취소·응답 순서·동시 편집 조건은 각 가이드의 직무별 계약을 따릅니다.

## 화면과 데이터

데스크톱 1440×1000과 모바일 390×844·320×640에서 확인했습니다. 모바일 두 폭 모두 새 12개 React·HTML 체험, 기본 코드와 모바일 관찰 화면에 가로 넘침이 없었습니다. [390px 측정](qa/advanced/mobile-390.json), [320px 측정](qa/advanced/mobile-320.json). 상태별 예시 36개도 320px에서 전환해 가로 넘침이 없었습니다. [예시 측정](qa/advanced/guides-320.json). 좁고 낮은 화면의 긴 표·반응형 세로 카드·문서 체험에는 필요한 세로 스크롤을 허용합니다. PC 표의 불필요한 세로 넘침은 셀 여백을 줄여 조정했습니다. 새 12개 PC 초기 화면은 체험 프레임 530px에 맞습니다. [PC 측정](qa/advanced/desktop.json). 목록의 작은 카드에서 잘리던 내용은 전용 행 높이·간격·문단 여백을 조정했고 12개 미리보기의 가로·세로 넘침이 없음을 확인했습니다. [목록 측정](qa/advanced/mini-metrics.json). 모달의 고정 높이·고정 제목·닫기와 이전에 확장한 체험 영역 구조는 유지합니다.

실제 iOS·Android 터치·OS 키보드·스크린 리더와 다른 브라우저 검수는 별도로 남아 있습니다. 폭 전환과 데스크톱 포인터 검사를 실기기 검증으로 기록하지 않습니다.

## 실제 데이터 반영

공개 API는 HTTP 200으로 51개 UI와 화면 예시 158개를 반환했습니다. 기존 39개 원고·게시본·메타 정보, 이력 82건과 기존 설정 8개는 SQL 문자열을 포함해 변경되지 않았습니다. 분류는 기존 순서를 유지한 채 ‘레이아웃과 모션’만 마지막에 추가했습니다. 새 12개는 revision 1·게시본·catalog 이력 1건씩을 가지며 현재 이력은 총 94건입니다. [보존 비교](qa/advanced/migration-result.json).

추가 직전 자동 백업은 기존 39개와 이력 82건을 포함합니다. 별도 이전 테스트와 실제 재시작 후 51개·이력 94건 및 기존 원문 보존을 재확인했습니다. 실제 콘텐츠를 시험 목적으로 편집·초기화하지 않았습니다.

[PC 표 상세](qa/advanced/data-table-desktop.png)와 [레이아웃 카드](qa/advanced/layout-cards-desktop.png)를 캡처해 시각 검수했습니다.

Easing 관찰에서 0% → 중간 위치 → 100% → 0%의 자동 반복을 확인했습니다. [재생 표본](qa/advanced/observation-loop.json). 새 대안 Data Table → Data Grid 클릭으로 연결된 상세 제목·주소가 갱신됐습니다. [모바일 조회 실패](qa/advanced/empty-state-mobile.png)도 시각 검수했습니다.

실제 다크 관리자에서 콘텐츠·게시 노출 51개와 시뮬레이션 카드 51개를 확인했습니다. ‘헤더’ 검색은 Sticky Header 1개를 반환했습니다. [관리 화면](qa/advanced/admin-advanced.png).
