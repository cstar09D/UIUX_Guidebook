# 배경 효과·카테고리·핫스팟 추가 형태

확인일: 2026-11-27.

사용자가 지정한 [배경 효과 9가지](https://orrd.co.kr/archive-view?id=6b091a763479272a42e991d7)를 Aside에서 확인했습니다. Mesh Gradient·Aurora·Grain·Dot Grid·Beams·Blob·Glow Orb·Particles·Starfield를 ‘배경 효과’ 분류로 추가해 총 77개입니다. 참고 사이트의 이미지·소스는 복제하지 않고 CSS·SVG와 독립적인 동작 코드로 구현했습니다.

## 화면과 동작

카테고리는 모든 화면 폭에서 줄바꿈합니다. 12개 버튼을 1440px에서는 2줄, 768px에서는 3줄, 390px에서는 4줄, 320px에서는 6줄로 표시합니다. 각 버튼이 컨테이너 안에 있으며 가로 스크롤과 페이지 가로 넘침이 없었습니다.

새 배경은 목록·관찰에서 자동 시연하고 상세에서는 색상 회전, 속도, 질감 강도, 점 간격, 빛의 강도, 입자 수를 조절합니다. 전경 텍스트를 별도 레이어에 남기고 배경은 포인터 입력을 받지 않습니다. 시연은 시간값으로 재현하며 실제 체험은 보이지 않는 탭·닫힘에서 프레임을 정리합니다. 각 항목에 사용 상황·주의·모바일 대안·직무별 안내·상태 예시·연결 대안·부분/전체 React·HTML 코드를 제공합니다.

Image Hotspot의 기존 하단 설명은 유지하고 ‘지점 옆 말풍선’을 추가했습니다. 목록 시연에서도 두 방식을 번갈아 보여줍니다.

- 마우스·Tab 초점에서 지점의 설명을 임시 표시합니다.
- 클릭·터치에서 고정하고 다시 누르기·닫기·Esc·바깥 클릭에서 닫습니다.
- 말풍선 실제 크기를 측정해 오른쪽→왼쪽→위/아래 순서로 배치하고 이미지 안쪽 8px 여백을 유지합니다. 리사이즈에서도 다시 계산합니다.
- 좁은 화면은 이름 중심의 작은 말풍선을 사용합니다. 자세한 사양은 기존 하단 설명 방식으로 확인할 수 있습니다.
- 닫기·Esc 뒤에는 원래 지점에 초점을 돌립니다. 같은 지점에 이미 초점이 있었어도 다음 Tab의 설명 표시가 막히지 않게 했습니다. Esc는 상위 상세 모달을 닫지 않습니다.

기존 핫스팟 원고는 작성 내용을 교체하지 않고 새 흐름·주의·예시 2개·직무 작업을 중복 없이 덧붙입니다. 초안과 게시본의 차이는 각각 유지합니다.

## 검사

최종 빌드와 자동 검사 56개가 통과했습니다. 전체 77개 가이드·검색어·코드 연결, 독립 React 부분/전체 예제 154개의 타입, HTML·CSS·JavaScript 구문, 배경 추가의 일회성 처리, 핫스팟 안내 추가 시 초안/게시/이력 보존을 포함합니다. 배치 함수는 좌우 끝·좁은 이미지·다양한 크기에서 여백을 지키는지 별도로 검사했습니다.

브라우저에서 배경 9종의 슬라이더를 React/HTML 모두 조작하고 PC 1440/모바일 320 폭으로 36개 화면을 측정했습니다. 가로 넘침이나 실행 영역 누락이 없었습니다. Particles는 실제 입자 수가 24→48로 바뀌는 것도 확인했습니다. 카테고리 4개 폭, 핫스팟 PC·모바일의 가장자리 배치와 닫기·초점 복귀·Esc 후 Tab 재진입·기존 패널 전환을 확인했습니다. 터치 전용 실기기 검사는 포함하지 않습니다. [측정값](qa/backgrounds/metrics.json).

실제 DB에서는 기존 67개 원고·게시본·메타와 이전 이력 111건을 원문으로 보존했습니다. 핫스팟은 guide와 revision만 갱신하고 새 배경 9개를 추가해 원고/게시본 77개·이력 121건이 됐습니다. 새 배경 분류와 일회성 처리 표시 외의 기존 설정도 보존했습니다. 추가 전 전체 백업은 기존 절차로 자동 저장됩니다. [데이터 보존](qa/backgrounds/data-preservation.json).
