# A0 상태 연동 · A1 신규 UI 6개

검수일: 2026-11-28. 실행 데모 등록 83개, Turso 관리 콘텐츠 83개. 신규 6개는 **초안**이며 기존 공개 콘텐츠 77개는 유지했다. 이번 변경은 로컬 구현·검수 상태로 GitHub push와 Vercel 배포를 실행하지 않았다.

6개 모두 목록·자동 시연과 실제 체험의 초기 트리를 공유한다. React와 독립 HTML은 같은 UI별 컨트롤러를 사용하며 복사하는 부분 코드에 필요한 함수만 포함한다. 전체 HTML 문서는 전체 예제를 선택할 때 제공한다.

## 상태 연동 계약

- 개발자가 `scenario-contract.mjs`에 허용 상태 ID를 등록한다. 관리자는 상태의 이름·발생 조건·처리 설명을 편집한다. 실제 동작과 화면 구성의 변경은 개발 소스에서 수행한다.
- 부모는 iframe의 `contentWindow`, nonce, 데모 ID, 허용 상태 키를 검사한다. iframe도 부모·nonce·데모 ID를 확인한다. 문자열을 실행 코드로 평가하지 않는다.
- 선택한 상태는 실제 Scene의 값·메뉴·로딩/오류 상태를 바꾼다. 사용자가 UI에서 상태를 바꾸면 부모의 선택·설명도 동기화된다.
- iframe에서 이미 처리한 상태가 부모로부터 돌아와도 사용자 값을 초기화하지 않는다. 새로운 상태나 초기화는 남은 타이머를 취소한다.
- 관리자에서는 등록되지 않은 상태를 임의 동작으로 연결할 수 없다. 새 UI의 필수 상태가 누락되거나 키가 일치하지 않으면 게시 검증에서 안내한다.
- 기존 77개는 매핑을 추측하지 않고 설명용 상태 화면을 유지한다. 실제 상태 연동은 이번 신규 6개에 먼저 적용했다.

## 발견하고 수정한 오류

메뉴를 열면 부모의 상태 설명 영역이 생겨 iframe 높이가 줄어든다. Context Menu의 resize 처리가 메뉴를 닫고 기본 상태를 보고하면서 설명이 다시 사라지는 되먹임이 발생했다. 현재는 열린 상태를 유지하고 위치만 다시 계산한다. 축소 후에도 열린 메뉴와 선택 상태를 유지하는 회귀 테스트를 추가했다.

기존 Starfield의 소수점 스타일이 브라우저 CSS 정규화와 달라 hydration 경고를 일으키는 부분도 확인했다. React와 HTML의 별 위치·크기·투명도·변환을 같은 정밀도로 맞췄다.

- 전체 테스트 **76개 통과**, `npm run build` 통과. 부분 React/TypeScript와 독립 HTML/CSS/JS 검증 포함.
- 실제 React 체험에서 6개 UI 조작, 상태 변경, 키보드·검색·실패/복구를 확인했다.
- 명령 검색에서 “디자인”은 일치하는 명령 1개만 표시하고 `3자 · 9 byte`를 표시한다. 실행 실패는 검색과 선택을 유지하며 재시도 성공 후 원래 버튼으로 돌아온다.
- HTML 체험 6개를 390px 화면에서 조작했다. 프레임 콘텐츠 폭/스크롤 폭은 모두 333/333px. 결과와 상태 선택의 동기화를 확인했다.
- React 체험 6개를 320px 화면에서 확장 상태로 확인했다. 외부 문서 폭/스크롤 폭은 모두 320/320px이고 내부에도 가로 넘침이 없었다.
- 메뉴의 이름 변경과 저장은 한글·영문·emoji를 텍스트로 처리한다. 관리자 원고도 실행 코드로 해석하지 않는다.
- DB 추가 작업의 미리보기, 추가 후 공개 77개 유지, 기존 원문·게시본·이력 보존, 재실행 시 0개 추가를 확인했다.

## DB와 운영 반영

로컬 SQLite는 수정하지 않았다. `scripts/add-expansion-drafts.mjs`는 Turso 연결이 없으면 실행하지 않으며 기본은 미리보기다. `--apply`에서 전체 내용을 검증하고 같은 트랜잭션에 복구 지점·초안·이력을 추가한다. 기존 동일 ID나 데모 연결은 보존하고 중복을 만들지 않는다.

```sh
node --env-file=.env.deploy.local scripts/add-expansion-drafts.mjs
node --env-file=.env.deploy.local scripts/add-expansion-drafts.mjs --apply
```

원격 추가는 이미 한 번 수행했다. 재실행 시 신규 추가 0개다. 새 초안의 가이드 후속 보정도 Turso에 초안 저장으로만 반영했다. 배포 전 새 demoId를 게시하면 운영 소스가 아직 해당 ID를 실행하지 못하므로 게시하지 않았다.
