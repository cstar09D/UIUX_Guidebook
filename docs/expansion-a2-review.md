# A2 입력 UI 6개 · 기존 입력 예제 보강

검수일: 2026-11-28. 실행 데모와 Turso 관리자 콘텐츠는 총 **89개**, 공개 콘텐츠는 **77개**다. A1에 이어 추가한 6개는 초안이며 이번 작업에서 GitHub push·Vercel 배포·게시를 실행하지 않았다.

각 UI에 영문·발음·한국어·별칭·움직임 검색어, 실무 추천과 대안 링크, 상세 상태 설명, 4개 직무별 업무·전달 항목·확인 사항을 추가했다. HTML/CSS/JavaScript와 React/TypeScript 부분 코드·전체 실행 예제도 제공한다.

A1과 같은 Scene·컨트롤러·상태 프로토콜을 사용한다. 목록 자동 루프와 상세 체험은 초기 트리와 핵심 입력 형태를 공유한다. 작은 목록에서는 용도 선택 같은 보조 옵션과 긴 도움말을 줄이고 상세에서는 모두 제공한다. 신규 6개의 상태 선택은 실제 UI를 바꾸고 직접 조작한 결과도 부모 선택에 반영한다.

## 기존 4개 보강

- **Text Field**: 플로팅 라벨, 필수/선택 전환. 선택 입력은 빈 값을 허용하고 값이 있으면 2~30자를 검증한다. HTML의 글자 카운터가 플로팅 라벨 내부에 끼어들지 않게 React와 위치를 맞췄다.
- **Textarea**: 필수 라벨과 10~200자·줄바꿈 도움말, 오류 후 입력 유지 설명을 보강했다. 기존 글자/byte 측정을 유지한다.
- **Checkbox**: 소식 복수 선택을 유지하고 필수 2개·선택 1개 동의 유형을 추가했다. 필수 두 개만으로 계속할 수 있으며 전체 동의에 선택도 포함됨을 표시한다. 부분 선택과 실제 활성 조건은 구분한다.
- **File Upload**: PNG/JPG 로컬 미리보기·교체·삭제, 같은 파일 재선택, 잘못된 교체 파일 선택 시 이전 유효 파일 유지, 이미지 디코딩 실패 안내. Object URL은 교체·삭제·해제 시 정리한다. 파일 입력을 비워 재선택을 허용하므로 기본 빈 파일명 문구 대신 별도 파일명을 표시하고 접근성 설명에 연결했다.

기존 4개는 직접 체험 안의 옵션으로 변형을 비교한다. 기존 77개의 설명용 상태 화면을 일괄 실제 상태에 연결한 것은 아니다. 실제 상태 프로토콜 매핑 대상은 A1·A2 신규 12개이며 나머지 항목의 상태 선택은 설명용 표시를 유지한다.

- 전체 회귀 테스트 **78개 통과**. 수량/시간 경계값, 입력 가이드 초안 추가 시 사용자 원고·게시본·다른 항목 보존과 재실행 중복 방지를 추가 검증했다.
- 최종 파일명 표시 보정 후 관련 코드·콘텐츠·회귀 검증 11개도 다시 통과했다.
- `npm run build` 통과. 생성되는 89개 UI의 독립 부분 코드·전체 코드 타입 검사도 통과했다.
- React에서 6개 신규 UI의 실제 입력·선택·오류·복구와 상태 동기화를 확인했다.
- 390px에서 6개 HTML 체험을 조작했다. iframe 본문 폭/스크롤 폭이 모두 348/348px로 가로 넘침이 없었다.
- 320px에서 6개 React의 확장/오류 상태를 확인했다. 외부 문서 폭/스크롤 폭은 모두 320/320px, iframe 본문은 278/278px였다.
- “서울” 검색은 무결과, “디”는 디자인만 표시했다. 자유 태그 허용을 켠 뒤에만 서울을 새 항목으로 추가할 수 있었다.
- 인증번호 `0012347` 입력은 `001234`로 제한되어 앞자리 0이 보존됐다. 코드 불일치·성공·만료·재전송 대기를 확인했다.
- 별점 4점 선택→2점 hover→포인터 이탈 시 4점 복귀를 확인했다. HTML에서 3점 선택 후 오른쪽 화살표로 4점이 선택됐다.
- Text Field의 `한A🙂`는 **3자·8 byte**였다. 필수/선택 전환, 플로팅 라벨과 카운터 위치를 양쪽 형식에서 확인했다.
- 양쪽 형식에서 선택 동의 없이 필수 두 개만으로 계속할 수 있었다. 이미지의 잘못된 교체·같은 파일 재선택·삭제도 확인했다.
- 목록 썸네일의 세로 잘림을 발견해 보조 안내 밀도를 조정했다. 6개 모두 카드가 미리보기 영역 안에 들어오는 좌표를 확인했다.

## Turso 반영과 보존

로컬 콘텐츠 SQLite는 수정하지 않았다. 신규 추가와 기존 원고 보강은 명시적 Turso 스크립트로 수행하고 작업 전 서버 복구 지점을 만들었다.

```sh
# 미리보기 → 필요한 경우에만 적용
node --env-file=.env.deploy.local scripts/add-expansion-drafts.mjs
node --env-file=.env.deploy.local scripts/add-expansion-drafts.mjs --apply
node --env-file=.env.deploy.local scripts/refresh-input-guides.mjs
node --env-file=.env.deploy.local scripts/refresh-input-guides.mjs --apply
```

추가 작업 전 복구 지점과 현재 데이터를 비교했다. 기존 83개 중 변경된 초안은 checkbox·text-field·textarea·file-upload 네 개뿐이며 사용자 도입 문구와 기존 원고는 유지하고 새 설명을 추가한다. 기존 공개본은 모두 같고 신규 6개는 초안이다. 두 스크립트 모두 재실행 시 변경 대상이 0개다.

검토 경로: 로컬 `/admin/preview?term=password-field`. 다음 기획 묶음은 A3 업무 흐름 6개와 표·필터·공유 보강이다.
