영문·발음·한국어 표현·별칭·동작 검색어, 실무 추천과 대안 링크, 상태별 처리 설명, 기획·디자인·퍼블리싱·개발의 업무/전달/검토 항목을 제공한다. 목록 자동 시연과 상세 체험은 같은 Scene·컨트롤러를 사용한다. HTML/CSS/JavaScript와 React/TypeScript의 부분 코드·전체 실행 예제도 생성한다.

신규 6개는 상태 선택이 실제 체험에 적용되고 직접 조작 결과도 부모 선택에 반영된다. 현재 실제 상태 계약은 A1~A3 **18개** 대상이다. 기존 77개 상태 선택은 설명용 화면을 유지하며 이번 보강 변형은 직접 체험 내부 옵션으로 선택한다.

## 기존 UI 보강

- **Data Table**: 열 머리글 정렬·방향 표시·동률의 원래 순서 보존. 비용 목록과 플랜 비교 표를 전환한다. 비교 표에서 ‘미제공’과 ‘확인 필요’를 구분한다.
- **Sorting**: 분류·내 담당 필터와 정렬 조합, 조건 칩 개별 해제, 전체 초기화. 조건을 지워도 선택한 정렬은 유지하고 사라진 칩의 초점은 관련 입력으로 돌린다.
- **Filtering**: 기존 사용자 정의 셀렉트를 유지하고 정렬·조회 실패·조건 초기화를 추가한다. 결과 없음과 조회 실패를 구분하며 실패 시 마지막 적용 조건과 기존 결과를 유지한다.
- **Icon Button / Bottom Sheet**: 카카오톡·페이스북·X·밴드·링크 복사 목록을 공통 메타데이터로 사용한다. PC 공유 패널과 좁은 화면의 시트, 메뉴로 돌아가기, 복사 실패 후 재시도·닫기·초점 복귀를 제공한다. 외부 SNS 게시와 클립보드 변경은 모의 동작이다.

## 검수 결과

- `npm run build` 통과. 생성되는 95개 독립 예제와 부분 React 코드의 타입 검사 포함.
- 회귀 테스트 **83개 통과**. 제스처 방향·경계값, 리스너 옵션과 정리, 신규 초안 추가와 가이드 보강의 게시본/사용자 원고 보존·재실행 중복 방지를 포함한다.
- React에서 신규 6개의 기본 조작·실패·복구를 확인했다. 스와이프는 포인터 -90px 이동 중 행이 `translateX(-90px)`로 따라갔고, 삭제 후 취소하면 s1/s2/s3 순서로 복원됐다.
- 당김 80px은 표시 40px이고 요청 없이 취소됐다. 140px은 표시 70px이며 놓은 후에만 8→9개·1회 갱신됐다. 목록 중간에서는 당겨도 갱신하지 않았고 실패 시 기존 9개를 유지했다.
- 알림 조회 실패는 기존 5개·미확인 2개를 유지했다. 인라인 실패는 `한A🙂` 3자·8 byte를 유지하고 재시도 성공 후 제목에 반영했다.
- 390px에서 신규 6개 HTML을 조작했다. 본문 폭/스크롤 폭은 모두 348/348px였다. 자동 불러오기는 하단 이동 후 6→12개 완료까지 확인했다.
- 320px에서 신규 6개 React의 열림·오류·제스처 상태를 확인했다. 바깥 문서 폭은 320/320px, iframe 본문은 278/278px로 가로 넘침이 없었다.
- 두 형식의 정렬·비교 표, 조건 조합·무결과·실패·칩 해제를 확인했다. 공유 패널의 복사 실패는 목록을 유지하고 재시도 성공 후 호출 버튼으로 초점이 복귀했다.
- 목록 잘림의 원인인 숨김 영역의 flex 표시를 수정했다. 인라인 읽기/편집 영역 전환을 재검수했고 숨긴 읽기 영역의 computed display가 `none`임을 확인했다. 새 UI 6개의 썸네일이 미리보기 영역 안에 들어온다.

## Turso 반영

콘텐츠는 로컬 SQLite가 아닌 Turso에 반영했다. 작업 전 서버 복구 지점을 생성했고 기존 89개의 공개본이 모두 동일함을 비교했다. 바뀐 기존 초안은 bottom-sheet·icon-button·data-table·sorting·filtering 다섯 개뿐이며 신규 6개는 모두 draft다. 추가·가이드 보강 스크립트의 재실행 변경 대상은 0개다.

```sh
# 기본 실행은 적용 대상 미리보기
node --env-file=.env.deploy.local scripts/add-expansion-drafts.mjs
node --env-file=.env.deploy.local scripts/refresh-workflow-guides.mjs
# --apply를 명시한 경우에만 서버 초안에 반영
```

로컬 검토 경로: `/admin/preview?term=notification-center`. 다음 기획 묶음은 A4 레이아웃·탐색 UI다. 신규 초안은 실행 소스 배포와 함께 검토한 후 게시해야 한다.
