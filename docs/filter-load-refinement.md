# 필터 선택창·추가 불러오기 보완

확인일: 2026-11-27.

Filtering의 ‘분류’는 기존 Select와 같은 필드·목록 패널·강조·체크 표시를 사용합니다. 선택창과 ‘내 담당만’ 체크박스는 라벨 아래의 같은 행에서 높이 중앙을 맞춥니다. 목록 미리보기·관찰·상세 React와 독립 HTML 코드에 함께 반영합니다.

키보드 방향키·Home/End·Enter/Space·Tab 확정과 Esc 취소, 바깥 클릭 닫기, 화면 공간에 따른 위·아래 펼침을 지원합니다. 필터 조건의 AND 계산과 개별 해제 후 초점 복귀를 유지합니다.

Load More의 제목 클릭은 선택 문구만 표시하던 방식에서 본문을 읽는 방식으로 보완했습니다. 이후 [목록·상세 일치 검토](alignment-consistency-review.md)에서 목록을 항상 유지하고 그 아래에 본문을 여는 형태로 정리했습니다. ‘설명 닫기’는 추가된 항목 수·실패 상태를 보존하며 원래 제목으로 초점을 돌립니다. 추가 조회의 개수와 실패·취소 안내를 분리해 본문 확인이 오류를 덮지 않습니다. 실패 후에는 ‘다시 불러오기’를 제공하고 실패 모의 체크를 해제해야 하는 점을 안내합니다.

불러오는 도중 본문을 읽어도 요청은 이어지며 완료 후 본문 초점을 빼앗지 않습니다. 취소·초기화는 대기 타이머를 정리합니다. 실제 외부 문서나 서버를 변경하는 동작은 아닙니다.

검수 결과와 화면은 `docs/qa/filter-load/`에 기록합니다. 실제 사용자 데이터는 수정하지 않습니다.

프로덕션 빌드와 자동 검사 49개가 통과했습니다. React·HTML 양쪽에서 선택창의 클릭·방향키·Tab 확정·Esc 취소·조건 AND·칩 해제, 본문 열기·복귀 초점, 조회 실패 후 기존 개수 보존·재시도·2→4→6개·취소 후 지연 추가 없음과 본문을 읽는 중 완료돼도 초점 유지를 확인했습니다.

데스크톱과 모바일 폭 390·320에서 선택창과 체크박스의 세로 중심이 일치하고 가로 넘침이 없었습니다. [측정값](qa/filter-load/metrics.json), [PC 선택창](qa/filter-load/filter-desktop.png), [모바일 선택창](qa/filter-load/filter-mobile.png), [모바일 본문](qa/filter-load/load-document-mobile.png). 취소 시 타이머 정리 외에 요청 식별자를 검사해 완료 직전 클릭과 늦은 콜백이 잘못된 상태를 만들지 않게 했습니다.

목록·관찰의 전체→분류→복합→0건 반복도 확인했습니다. 실제 로컬 DB의 원고·게시본·메타 51건씩, 이력 94건과 설정 10개를 수정 전후 원문으로 비교해 모두 보존했습니다. [데이터 보존](qa/filter-load/data-preservation.json).
