# 모달 체험·대안 카드·날짜 형태 분리

확인일: 2026-11-27. 기간 날짜 선택을 단일 날짜 선택과 독립된 콘텐츠로 분리해 목록·관리 등록부는 39개입니다. 원래 기본 유형 50개에 추가 형태를 별도 관리하며 기본 유형의 남은 제작 범위는 12개입니다.

## 변경

- 아이콘 버튼의 패딩과 SVG 배치를 통일했습니다. 복사·보관·공유 아이콘을 버튼의 가로·세로 중앙에 놓고 hover·누름·초점 상태를 제공합니다. 보관 완료의 배경·테두리·색은 유지되고 보관 취소에서 돌아옵니다. 복사·공유 모의 실행에도 완료 강조를 남깁니다.
- 상세 모달 높이는 900px과 화면 높이 상한을 유지합니다. PC 체험 영역은 실제 모달 본문의 높이를 기준으로 남는 공간을 채웁니다. 짧은 UI는 프레임 중앙에 놓고 긴 내용은 위에서 시작해 필요한 경우 스크롤합니다. 모바일은 전체 모달 본문과 체험 높이를 구분합니다.
- 대안 링크를 목록과 같은 장면의 자동 반복 애니메이션·한국어 설명·밑줄 있는 UI 이름을 담은 카드로 변경했습니다. 모달에서 목록 재생이 멈춰도 대안 카드는 독립적으로 재생합니다. 화면 밖과 문서 숨김에서는 재생을 멈춥니다.
- `Date Picker (Single)`과 `Date Picker (Range)`를 목록·등록부·가이드·코드에서 분리했습니다. Single에는 기간 전환 버튼이 없습니다. Range는 입력창 없이 한 달력에서 시작일과 마감일을 차례로 고릅니다. 첫 날짜·두 끝·사이 범위·숙박 일수를 보여주며 월 이동·방향키·적용·마지막 적용으로 취소를 지원합니다.
- 기간 달력은 해당 월에 필요한 주만 표시합니다. 예시의 2026년 11월과 12월은 각각 5주이며 불필요한 여섯 번째 주를 생략했습니다. 11~12월, 최소 1박, 주말 허용은 예제 정책입니다.

## 검증

프로덕션 빌드와 자동 검사 43개가 통과했습니다. 등록 연결 39개, 가이드·발행 검증, 독립 React 부분·전체 코드 78개 타입 검사, HTML·CSS·JavaScript 구문 검사, 검색·반복 재생·저장·가져오기·추가 이전을 포함합니다.

브라우저 검증에는 Aside와 별도 검증 DB의 프로덕션 서버를 사용했습니다.

| 항목 | 확인한 결과 |
|---|---|
| 아이콘 | 세 SVG의 중심 좌표와 버튼 중심 좌표 차이가 가로·세로 모두 0px. React·HTML 보관 강조와 취소 동작 확인 |
| 높이 | 1440×1000에서 모달 900px 유지, 체험 프레임 530px. Checkbox는 React·HTML 모두 문서 높이와 프레임 높이가 같음 |
| 작은 UI | Icon Button 카드의 위·아래 여백이 각각 약 122px로 일치 |
| 기간 | 별도 텍스트 입력 없음, 시작·마감·범위 강조, 11/16~20의 4박, 월을 넘는 11/30~12/2의 2박, 적용·취소 확인 |
| 단일 | 기간 전환 없음, 11월 18일 직접 입력·적용 유지 |
| 대안 | 이름에 밑줄과 애니메이션 표시, 여러 시점의 장면 변화와 Range 상세 이동 확인 |

PC 1440×1000에서 React 체험 39개 전체의 가로·세로 넘침이 없었습니다. [측정값](qa/modal-date-split/pc-sizing.json). 높이를 750px로 낮춰 체험 영역이 348px이 됐을 때는 더 긴 체크박스 카드가 위쪽 25px에서 시작하며 윗내용을 잃지 않았습니다. [상단 정렬 측정](qa/modal-date-split/tall-alignment.json). 모바일 390px·320px에서 아이콘·체크박스·단일·기간의 React·HTML 16개 조합은 가로 넘침이 없었습니다. 좁은 화면의 일부 긴 내용에는 필요한 세로 스크롤이 남습니다. [모바일 측정값](qa/modal-date-split/mobile-sizing.json).

## 데이터 적용 원칙

새 기간 선택 콘텐츠는 기존 id를 덮어쓰지 않는 추가 이전으로 등록합니다. 기존 단일 날짜 콘텐츠는 기본 이름과 기간 관련 가이드만 정리하며 다른 UI의 명칭·본문·분류·순서·게시·휴지통 상태와 기존 이력은 보존합니다. 적용 전에 자동 복구 지점을 생성하고 완료 표식을 기록해 재시작 시 반복하지 않습니다.

실제 공개 API는 200·39개를 반환합니다. 기존 37개 콘텐츠의 초안·게시본·메타 정보와 이력 80건·기존 설정 7개를 원문 비교로 보존했습니다. 단일 날짜 콘텐츠 1개를 정리하고 새 기간 콘텐츠 1개를 추가해 이력은 82건입니다. 추가 전 38개·이력 80건, 단일 가이드 정리 전 39개·이력 81건을 담은 복구 지점을 각각 생성했습니다. [비교 결과](qa/modal-date-split/migration-result.json).
