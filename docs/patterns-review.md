# 3단계 복합 패턴·진행 상태 UI 검수 기록

확인일: 2026-11-26. [출시 50개 계획](planning/release-50.md)의 3단계 12개를 추가해 총 38개를 구현했습니다. 공식 자료, 동작 범위와 재생 순서는 [3단계 명세](planning/patterns-spec.md)에 정리했습니다. 남은 12개는 4단계 예정 항목입니다.

## 자동 검사

Next.js 프로덕션 빌드와 자동 테스트 38개가 통과했습니다. 등록 연결 38개, 게시 가능한 원고와 상황별 화면 예시 117개, 직무별 안내, HTML·CSS·JavaScript 구문, 독립 React 부분·전체 코드 76개 타입 검사, 검색·반복 재생·저장·충돌·백업·추가 이전을 포함합니다. 날짜의 실제 유효성·범위·휴무, 파일의 크기·확장자·MIME 경계도 검사했습니다. 저장소 테스트에는 별도 임시 DB를 사용했습니다.

HTML 초기 화면은 React 장면의 마크업에서 빌드 시 생성하고, 상호작용은 독립 JavaScript로 제공합니다. 다운로드한 HTML에는 React 실행 환경이 필요하지 않습니다.

## 실제 조작

Aside 브라우저와 별도 검증 DB를 사용하는 프로덕션 서버에서 새 12개의 React·HTML 두 형식을 모두 조작했습니다.

| UI | 확인한 동작 |
|---|---|
| Floating Action Button | 빈 이름 오류, 생성 후 목록·개수 갱신, 취소 시 생성하지 않음 |
| Date Picker | 11월 31일 형식상 날짜와 11월 26일 예약 불가 구분, 달력 날짜·월 이동, 방향키, 불가 날짜의 이유, 선택·적용, Esc 시 입력 유지 |
| File Upload | 실제 File 객체 선택, PDF 성공, ZIP·2MB 초과 오류, 70% 실패 후 재시도, 취소 후 지연 완료 없음 |
| Navigation Drawer | 목적지 선택·본문·현재 위치 일치, 목적지 제목 초점, Esc와 실행 버튼 초점 복귀 |
| Bottom Navigation | 세 목적지 전환, 현재 위치 표시, 홈 메모 보존과 제목 초점 |
| Menu Button | 위 방향키로 마지막 항목 열기, 항목 이동, Esc·Tab, 복사 횟수, 고정, 보관·되돌리기 |
| Stepper | 이름·범위 오류와 초점, 이전 단계 값 보존, 완료한 단계 재방문, 최종 확인 후 생성 |
| Card | 독립 저장 버튼과 본문 링크 분리, 상세·돌아가기, 저장 상태·제목 초점 유지 |
| List | 항목 열기, 완료·미완료, 완료 항목 숨김·빈 결과·다시 표시, 사라진 행의 초점 복구 |
| Alert Dialog | 취소 우선 초점, Esc로 미삭제, 실패 시 문서·대화상자 유지, 성공·복원, 실행 버튼 초점 복귀 |
| Progress Bar | 정상 100%, 실패 60% 유지, 취소 뒤 지연 완료 없음, 다시 시작 |
| Loading Spinner | 정상·빈 결과·오류 구분, 지연 안내, 취소 뒤 지연 완료 없음, 재시도와 busy 해제 |

파일 전송과 생성·삭제·조회는 외부 요청 없이 예제 상태를 변경하는 모의 동작입니다. 파일 내용 검사와 서버 업로드, 실제 라우터·권한 연동은 가이드의 통합 시 확인 사항입니다.

## 화면·코드

- PC 1440×1000, 모바일 폭 390×844·320×640에서 새 12개를 확인했습니다. 상세 높이는 기존 900px과 화면 높이 상한을 유지합니다.
- 두 모바일 폭에서 React·HTML 체험, 코드, 모바일 관찰 장면에 가로 넘침이 없었습니다. [390px 측정값](qa/patterns/pattern-responsive-390.json), [320px 측정값](qa/patterns/pattern-responsive-320.json).
- 목록의 새 12개 장면은 카드 아래로 넘치지 않습니다. [측정값](qa/patterns/pattern-mini-metrics.json).
- 새 UI의 상황별 화면 예시 36개를 모두 전환해 320px 폭에서 가로 넘침이 없음을 확인했습니다. 예약 불가 그림은 11월 26일을 구분해 표시합니다. [측정값](qa/patterns/pattern-guide-320.json).
- PC 파일 첨부·로딩 체험의 여백을 조정해 본문 높이가 프레임 430px 안에 맞도록 했습니다. [측정값](qa/patterns/pattern-compact-sizes.json).
- [PC 날짜 선택 화면](qa/patterns/date-picker-desktop.png)과 [모바일 파일 첨부 화면](qa/patterns/file-upload-mobile.png)을 캡처해 배치와 잘림을 시각적으로 확인했습니다.
- UI 부분 코드가 기본이며 복사 완료 응답을 확인했습니다. 전체 실행 예제를 선택한 뒤 내려받은 `date-picker.html`은 독립 HTML 문서와 해당 UI의 실행 코드를 포함했습니다. OS 클립보드 내용을 직접 읽어 대조한 결과는 아닙니다.
- Progress Bar 관찰에서 완료 → 시작 전 → 진행 중 → 완료 직전 → 완료로 자동 반복되는 것을 확인했습니다. 전체 장면의 연결과 반복 시간은 자동 검사에도 포함합니다.

## 실제 데이터 반영

실제 사용자 DB의 기존 26개 초안·게시본·메타 정보, 편집 이력 30건과 기존 설정 5개를 SQL 원문으로 비교해 보존을 확인했습니다. 새 12개는 각각 revision 1, catalog 이력 1건과 게시본을 가집니다. 공개 API는 200 응답과 게시 항목 38개를 반환합니다.

추가 전 26개를 담은 `data/backups/catalog-*.json` 복구 지점을 자동 생성했습니다. [비교 결과](qa/patterns/migration-result.json). 실제 콘텐츠를 검증 목적으로 수정하거나 초기화하지 않았습니다.

실제 관리자에서 콘텐츠·게시 노출 38개, 시뮬레이션 등록 38개와 각 연결 콘텐츠 1개, 새 복구 지점 표시를 확인했습니다. 공개 목록에서 `달력에서 선택`은 Date Picker 1개를 반환하고 지우기 후 38개로 복원됐습니다.

## 후속 검증

폭 변경 검사는 iOS·Android 실기기 검증을 대체하지 않습니다. 실제 한글 IME 조합, OS 파일 선택창·키보드·터치, VoiceOver/TalkBack과 여러 브라우저 검수는 남아 있습니다. 날짜 선택 예제는 고정된 2026년 11~12월 예약 조건을 설명하며 범용 달력 라이브러리가 아닙니다. 다음 제작 범위는 4단계 12개입니다.
