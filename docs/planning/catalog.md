# UI 용어 60개 후보와 데모 방향

상태: 1차 분류·편집 초안. 첫 출시에서는 아래 후보 중 40~60개를 필수 원고·데모·두 코드 형식까지 완성한다. 발음과 한국어 표현은 사이트 편집안이다. 출처 ID는 [조사 기록](research.md)의 문서와 대응한다. 목록·개요 출처는 후보 발굴 근거이며 개별 용어의 상세 검수 완료를 의미하지 않는다.

검색어 열은 동의어가 아니라 검색 유입 문구다. 실제 동의어·통칭·관련 용어·변형 관계는 콘텐츠 작성 때 각각 기록한다. 유형 표기는 `컴포넌트 / 패턴 / 레이아웃 / 모션`을 사용한다. 목록 재생은 아래 체험의 대표 전환을 짧게 보여주고 상세에서는 직접 조작한다.

각 후보의 이미지 구성·시연 시간·전환 속성·직접 조작·모션 감소 대안은 [60개 UI 동작 명세](ui-motion-specs.md)에 같은 C01~C60 ID로 연결했다. 공통 실행 구조는 [이미지와 애니메이션 구현 계획](visual-motion-plan.md)을 따른다.

## 공통 환경 표시와 완성 조건

각 후보는 PC·모바일 지원 여부와 별도로 마우스·키보드·터치, 좁은 화면 제약, 대안과 조건을 개별 검수한다. 이 표의 후보 단계에서 모든 환경 지원을 확정하지 않는다.

각 항목의 완성 조건은 명칭 세트·정의·사용/주의 상황·별칭 관계·검색어·짧은 재생·실제 체험·4개 직무 안내·두 코드 형식·PC/모바일/입력 조건·조건부 대안·출처·확인일이 모두 갖춰지는 것이다. 대안이 필요하지 않은 항목도 그 이유를 기록한다.

대표 설계 6개는 C31 모달, C27 아코디언, C13 콤보박스, C44 스켈레톤, C46 데이터 그리드, C36 바텀시트다. 이 조합으로 레이어·펼침·입력·비동기 상태·복합 키보드·작은 화면을 먼저 검토한다.
