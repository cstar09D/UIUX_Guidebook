# 기간 선택·펼침 버튼·실무 가이드 개선

확인일: 2026-11-27. 기존 38개 UI 안에 체험 형태를 추가하고 전체 사용 상황·대안을 개선했습니다. 4단계 콘텐츠 추가와 별개인 수정입니다.

## 변경 사항

- Icon Button의 문자 기호를 복사 문서·보관함·연결된 공유 노드의 SVG 아이콘으로 바꿨습니다. 목록·관찰·React·독립 HTML에서 같은 모양과 행동 이름을 사용합니다. [화면](qa/refinements/icons-desktop.png).
- Date Picker는 기본 하루 선택을 유지하며 기간 선택을 추가했습니다. 시작일·종료일 직접 입력, 달력의 두 끝 날짜·사이 날짜 강조, 최소 1박과 숙박 일수, 월 경계, 잘못된 날짜·순서 오류, 임시 선택 취소를 다룹니다. 여행 예시는 2026년 11~12월이며 하루 상담 예약의 휴무 정책과 달리 주말도 허용합니다. [화면](qa/refinements/date-range-desktop.png).
- Floating Action Button은 기본 단일 생성 버튼을 유지하며 새 노트·새 체크리스트 보조 버튼 펼침을 추가했습니다. 각 항목의 휴지통, 마지막 삭제의 원래 위치 복원, 빈 목록과 초점 복귀를 제공합니다. 보조 버튼은 다시 누르기·Esc·행동 선택으로 접힙니다.
- 전체 38개에 실무 작업 예시와 UI 선택 기준을 작성했습니다. 공식 문서 링크와 추천 상황을 분리하고 사용 상황 바로 다음에 대안 비교를 배치했습니다. 각 UI의 두 대안은 명칭을 눌러 상세로 이동하며 창을 겹쳐 쌓지 않습니다.
- 관리자에서 대안의 연결 UI를 선택할 수 있습니다. 저장·가져오기는 연결 id를 보존하며 등록되지 않은 id는 거절합니다. 숨김·비공개 등으로 공개 대상이 없으면 설명만 남기고 연결할 수 없음을 표시합니다.

펼침 행동의 참고는 [Material UI Speed Dial](https://mui.com/material-ui/react-speed-dial/), 기간 입력·달력 조합의 참고는 [Adobe React Aria DateRangePicker](https://react-aria.adobe.com/DateRangePicker)입니다. 기존 [WAI-ARIA 날짜 선택 예제](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/datepicker-dialog/)의 키보드 이동을 유지했습니다. 해당 라이브러리를 설치한 구현은 아니며, 펼침 버튼은 이름 있는 일반 버튼 그룹과 Tab·Esc를 사용하는 이 프로젝트의 예제입니다. 날짜 정책과 최소 숙박은 예제 정책입니다.

## 검증

프로덕션 빌드와 자동 검사 42개가 통과했습니다. 독립 React 부분·전체 코드 76개 타입 검사와 HTML·CSS·JavaScript 구문, 실제 날짜·기간 경계, 76개 대안 연결의 유효성, 저장·가져오기, 가이드 갱신의 반복 실행과 기존 데이터 보존을 포함합니다.

Aside 브라우저에서 React와 독립 HTML 양쪽을 조작했습니다.

| 항목 | 확인 결과 |
|---|---|
| 날짜 기간 | 빈 값·역순 오류, 11/16~20의 4박, 11/30~12/2의 월 경계와 2박, 범위 강조, Esc 시 원래 값 보존 |
| 액션 버튼 | 기본 생성·이름 오류, 보조 체크리스트 생성, Esc 접기, 항목별 삭제·복원, 전체 삭제 후 빈 상태와 복원 |
| 대안 이동 | 38개 모두 대안 2개 표시, 각 첫 대안 클릭 후 URL·제목·단일 상세 일치, 닫기 후 목록과 원래 카드 초점 복귀. [기록](qa/refinements/alternative-links.json) |
| 아이콘 | SVG 3개와 이름 확인, PC 캡처에서 복사·보관·공유의 형태 확인 |

화면 폭 검증은 데스크톱 브라우저의 1440px·390px·320px 환경에서 수행했습니다. 실기기의 터치·OS 키보드·스크린 리더까지 검증한 결과는 아닙니다. 예제의 생성·삭제는 로컬 시뮬레이션이며 서버 권한·실제 삭제·복구 API는 직무별 안내에 통합 시 확인 사항으로 명시했습니다.

모바일 여백을 추가 조정해 390px·320px에서 기간 입력과 펼침 버튼은 체험 프레임 390px 안에 들어오며 가로 넘침도 없습니다. [최종 측정값](qa/refinements/mobile-final.json), [펼침 화면](qa/refinements/speed-dial-mobile.png). 날짜의 하루·기간 자동 반복은 두 형태 모두 아래가 잘리지 않습니다. [반복 측정값](qa/refinements/preview-final.json). React·HTML 모두 주 버튼에서 Tab을 누르면 첫 보조 버튼으로 이동하고 Esc로 주 버튼에 돌아오는 것을 확인했습니다. 코드의 가로 넘침과 세 UI의 두 형식은 [폭별 기록](qa/refinements/responsive.json)에 정리했습니다.

## 실제 데이터 보존

기존 38개의 가이드 요청 항목을 갱신했습니다. 나머지 영문·발음·한국어 명칭, 요약·검색어·별칭, 순서·노출·삭제 상태 등은 원문 비교로 보존을 확인했습니다. 날짜·액션 버튼 이외에는 정의·사용 흐름·예시·직무 안내도 보존했습니다. 두 확장 UI에는 예시와 안내를 보완해 총 상황별 화면 예시는 121개입니다.

기존 이력 42건과 기존 설정을 보존했고 갱신 이력 38건을 추가했습니다. 실행 전 자동 복구 지점에는 38개와 이전 이력 전체가 들어 있습니다. 재시작해도 갱신을 반복하지 않습니다. [비교 결과](qa/refinements/migration-result.json).
